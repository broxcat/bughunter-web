# BugHunter Web v1.0.0

BugHunter Web is a Black-box bug bounty research platform:

**Targets → Scope → Recon → Research Plan → Research → Findings → Report**, with persistent Coverage, shared Evidence and Retest history.

This release brings together:

- Targets with program policy, required User-Agent and authoritative Scope. A discovery never grants authorization.
- Structured Recon and authenticated Recon using explicitly authorized test accounts, with separate runtime contexts and visibility differentials.
- Recon AI synthesis through the configured provider, with real OpenRouter/Gemini and Ollama acceptance, strict application validation and readable deterministic facts when narration is unavailable.
- A deterministic Research Plan and persistent Research Coverage, including negative results and distinct authentication comparisons.
- A minimal Evidence Vault connecting Recon references, HTTP captures, Burp references and Research evidence to hypotheses, Findings, Reports and Retests through durable IDs/provenance.
- Recon history and diffs: new, changed, unchanged and not observed this run. Absence does not prove removal.
- Native Codex Research and Claude Research, common scope/plan/Coverage context, persistent terminals and reconnect. Authenticated Claude context inference is now validated.
- Burp MCP, guarded HTTP/1.1/HTTP/2, browser/proxy evidence and shared security boundaries.
- Human-promoted and reviewed Findings, explicit lifecycle/submission metadata, immutable Retest results and historical Reports.
- Additive migrations, fresh-install acceptance and disposable upgrade/fixture-preservation checks.

Coverage does not prove safety. Observations, scanner matches and confirmed Research hypotheses do not automatically become Findings. Promotion, evidence review and validation remain human actions. BugHunter supports the researcher; it does not promise to discover every vulnerability.

## Validation

1,385 distinct automated cases passed with zero failures (1,368 suite cases with PostgreSQL/Redis enabled plus all 17 explicit network cases). Migration/drift, browser, authentication, queue resilience, Research console/isolation, real Burp and model acceptances are recorded in [the final audit](../v1-release-audit.md).

Production dependency audit: zero vulnerabilities. Eight moderate development-only tooling reports are documented as `ACCEPTED_DEV_TOOLING_RISK`; no compatible supported fix is currently available. No high/critical advisory is accepted by this release.

The current local DB was freshly installed after a host disk-full incident recreated its PostgreSQL volume. The earlier 437-row historical-preservation acceptance remains separate documentary evidence; those rows are not represented as current data.

## Upgrade

Preserve local work and existing database/Research volumes. Build from a clean checkout. These commands apply when `main` points to this release; if it has advanced, select the `v1.0.0` tag before building for the exact published version.

```sh
git pull --ff-only origin main
docker compose build web worker
docker compose run --rm --no-deps web npx prisma migrate deploy
docker compose up -d --no-deps --force-recreate web worker
docker compose exec web npx prisma migrate status
docker compose ps
```

Verify HTTP health, login and the `BugHunter Web · v1.0.0` footer. Do not delete Docker volumes or reset migrations during upgrades. No new migration is introduced by the release-finalization commit; existing installations must still apply the full migration chain before starting the updated application.

## Known limits

- Black-box only; experimental White-box execution is retired. Historical metadata remains readable.
- Research and external AI providers require their own valid operator authentication/configuration. No silent provider switch is performed.
- Scope remains the authorization source; IP/CIDR assets are documentary where the current execution engine does not support them.
- Recon comparisons are manual; automated scheduling is not part of v1.0.0.
- The minimal Vault supports HTTP request/response metadata, Recon artifacts, Burp references and Research evidence. Additional media/upload formats are not advertised.
- Runtime and AI evidence can be incomplete. Coverage records only the tests and contexts actually recorded, and an absence in Recon does not establish removal or safety.
