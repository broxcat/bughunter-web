# BugHunter Web v0.1.0

First tagged source release of BugHunter Web.

- Target-centric Scope → Recon → Research → Findings workflow.
- Structured Scope Assets with independent Format, Type and Asset Value; explicit manual Format overrides.
- Adaptive, bounded Recon playbooks, structured artifacts, provenance, scan changes and deterministic scope.md exports.
- Gobuster 3.8.2 complements FFUF with scoped directory discovery and supplementary DEEP wildcard DNS discovery.
- Minimal Scope Recon console and cached, structured Ollama summaries for assets and Targets, using existing Settings.
- Persistent native Codex and Claude Research consoles, shared Recon intelligence and Burp MCP integration.
- Confirmed Target deletion and per-console lifecycle cleanup, including active processes and exclusive conversations/workspaces.

## Upgrade

Apply additive Prisma migrations, including `20261103220000_recon_summaries`, and rebuild/recreate web and worker. Follow `docs/recon-ollama-summary.md`. Preserve existing data, secrets and authentication volumes.

## Limitations

Use only explicitly authorized scopes. Tool unavailability, blocking and bounded coverage produce partial Recon. Exact hosts never grant wildcard/vhost authorization; automatic Gobuster vhost discovery is disabled. IP/CIDR remain documentation-only where no executor exists. Ollama requires an explicitly configured reachable endpoint/model and a running worker; summaries can fail independently and are AI interpretations, never confirmed Findings. Native model authentication remains operator-managed. Cleanup retains a revocation marker and requires a retry if infrastructure cannot confirm process shutdown.

GitHub supplies the source ZIP and tar.gz automatically; no environment data or credentials are included.
